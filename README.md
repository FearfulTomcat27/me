# Yu Yong - 个人主页

基于 Next.js 构建的个人作品集网站，展示项目经历、技能和联系方式。

## 技术栈

- **框架**: Next.js 16 + React 19
- **样式**: Tailwind CSS v4
- **图标**: Lucide React
- **主题**: next-themes（深色/浅色模式）
- **部署**: Vercel

## 本地开发

```bash
pnpm install
pnpm dev
```

访问 [http://localhost:3000](http://localhost:3000)。

## 构建部署

```bash
pnpm build
pnpm start
```
